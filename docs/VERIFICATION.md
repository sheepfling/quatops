# Verification

This records the checks for the QuatOps review candidate. NumPy is an optional
runtime dependency. SciPy is used only as a development oracle. The public
NumPy paths select both convention and storage order, for example
`quatops.numpy.hamilton.xyzw`; importing `quatops.numpy` alone imports no array
operations or NumPy dependency.

## Source suite and static checks

The source suite passed on CPython 3.12.14 with NumPy 2.3.5 and SciPy 1.17.0:

```sh
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src /path/to/pytest -q
```

Result: **98 passed, 1 skipped, 857 subtests passed**. The skip is the
extended-range check: this platform's `longdouble` has no wider range than
float64. Ruff 0.17.3 and mypy 2.4.1 passed on `src`, `tests`, and
`experiments`.

The installed wheel was checked outside the checkout on three interpreters:

- CPython 3.9.6 without NumPy or SciPy: **99 passed, 41 skipped**.
- CPython 3.9.6 with NumPy 2.0.2 and without SciPy: **99 passed, 8 skipped**.
- CPython 3.12.14 with NumPy 2.3.5 and SciPy 1.17.0: **99 passed, 1 skipped**.

A no-network install and test of the sdist on CPython 3.9.6 passed **99 tests
with 41 dependency skips**. The sdist contains the package source and tests,
plus the README and license required for package metadata and distribution. It
excludes `docs/`, `experiments/`, generated bytecode, and binary wheel/sdist
artifacts. The wheel contains `py.typed` and all four fully qualified NumPy
modules.

Installed-wheel consumer checks passed with mypy 2.4.1, Pyright 1.1.414, and
ty 0.0.95 for both scalar and NumPy examples; each checker rejected the
intentionally invalid fixture. Ruff and mypy also passed on source.

## Build metadata and artifacts

The project metadata is defined in `pyproject.toml`; setuptools-scm supplies
the version from Git metadata and is a build-only dependency. NumPy and SciPy
are optional development extras, not runtime requirements. The build test used
CPython 3.9.6, setuptools 82.0.1, setuptools-scm 10.3.4, and wheel 0.48.0.
The tested source archive excluded the retained historical milestone snapshots;
those remain in the earlier review branch rather than the current PR diff.

## Inverse reciprocal sample

The dataclass inverse now computes the reciprocal of its scaled denominator
once and reuses it for all four components. On CPython 3.12.14, a local
200,000-call microbenchmark (five repeats, best time) took 0.698 seconds before
and 0.653 seconds after that change. A separate sample of 1,000 random inputs
showed a maximum relative component difference of `5.4e-16` compared with the
previous expression. This is a local timing sample, not a general performance
guarantee; parity tests cover ordinary, very large, and very small inputs.

## Scope and limitations

The four NumPy modules contain explicit convention/layout kernels and shared
internal validation helpers. Tests verify their exports resolve directly to
those kernels and that namespace modules do not offer incomplete default
operations. Rotation-cancellation and subnormal conversion-rounding limits
remain documented in [the API contract](API.md) and
[the numerical investigation](ROTATION_NUMERICS.md). The implementation does
not claim correctly rounded results for arbitrary float64 extremes.
