# CSPICE through SpiceyPy

This oracle uses a pinned SpiceyPy Python binding and the CSPICE binary that it
loads. Record wrapper and toolkit versions separately; neither the package
name nor NASA/JPL authorship selects QuatOps' algebra convention.

- [SpiceyPy 8.3.0](8.3.0/README.md): quaternion products, matrix/frame
  direction, Euler routes, axis-angle and quaternion-derivative semantics.
