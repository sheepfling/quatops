# MuJoCo oracle

Pinned low-level math routines from the official `mujoco` Python package are
captured under each version directory. Captures exercise the native MuJoCo
library through its documented binding, without a model, simulation, viewer,
or QuatOps import.

- [3.17.0](3.17.0/README.md): quaternion algebra, Euler construction,
  angular-velocity derivatives, integration, and tangent Jacobians.
