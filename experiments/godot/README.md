# Godot captures

Pinned native capture projects are organized by Godot version:

- [Godot 4.7 stable](4.7-stable/README.md), official Windows float32 build.
- [Godot 4.8-dev1](4.8-dev1/README.md), official Windows float32 build.

Keep future releases in sibling version folders and retain each version's
capture and fixture. The shared layout is documented in
[`experiments/README.md`](../README.md).
