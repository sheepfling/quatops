# VTK 9.6.2 glTF importer capture

The exact exporter, Wave 2 input assets, Linux native observations, and
independent TRS/animation comparison are retained in
[`experiments/quatops_capture_wave2`](../../../../../quatops_capture_wave2/README.md).
The capture used VTK 9.6.2 with Python 3.13.5 on Linux x64; it includes twelve
static asset loads and one hundred animation samples.

The versioned raw manifest and observations are in
[`tests/golden/transports/gltf/2.0.0/vtk/9.6.2`](../../../../../../tests/golden/transports/gltf/2.0.0/vtk/9.6.2/manifest.json).
