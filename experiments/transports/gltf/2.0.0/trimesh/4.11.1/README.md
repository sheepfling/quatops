# Trimesh 4.11.1 glTF importer capture

The exact exporter, Wave 2 input assets, Linux native observations, and
independent TRS comparison are retained in
[`experiments/quatops_capture_wave2`](../../../../../quatops_capture_wave2/README.md).
The capture used Trimesh 4.11.1 with Python 3.13.5 on Linux x64 and covers
twelve static asset loads. It does not claim animation sampling.

The versioned raw manifest and observations are in
[`tests/golden/transports/gltf/2.0.0/trimesh/4.11.1`](../../../../../../tests/golden/transports/gltf/2.0.0/trimesh/4.11.1/manifest.json).
