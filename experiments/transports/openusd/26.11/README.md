# OpenUSD 26.11 capture

## Reproduction

The run used `usd-core==26.11`, OpenUSD 26.11, and CPython 3.14.6 on Windows
x86-64. The lock and frozen native libraries are identified in
[`native_rotation.json`](../../../../tests/golden/transports/openusd/26.11/native_rotation.json).

```powershell
uv sync --locked --python 3.14.6
uv run --locked python capture_openusd.py
```

The input stage is [`assets/rotation_stack.usda`](assets/rotation_stack.usda).
It is generated by the capture script and hashed in the fixture. It contains a
Y-up metadata declaration, positive-axis translation probes, an orient-op
parent, a mixed `rotateXYZ` and translation child, and a reset-stack child.

## Captured API surface

The capture records `Gf.Quatf` and `Gf.Quatd` coefficient access, products,
length, normalization, conjugate, inverse and point action; `Gf.Rotation`
axis/angle, quaternion and matrix routes; and `Gf.Slerp` for the frozen
interpolation inputs and weights. It then records `UsdGeom.Xformable` op order,
local matrices, cached world matrices and point/direction action from the saved
stage. The stack probes include a noncommuting rotate op, nested composition,
and `resetXformStack`.

OpenUSD's quaternion stores a real coefficient and an imaginary `Vec3` in that
order. `Gf.Rotation` angle input/readback is degrees; the capture explicitly
converts the corpus radians. In this version, `GetAngle` retains the sign and
full-turn magnitude of these axis-angle inputs. `UsdGeom` evaluates the saved
op list using row-vector matrices; the captured child world matrix equals its
local matrix followed by the parent matrix. The stage up-axis token remains
metadata: the world translations of its authored positive-axis probes are
preserved. This does not establish any application's chosen source frame or
model-forward axis.

## Limits

This is a pinned Python distribution and build on one platform. It establishes
`Gf` and `UsdGeom` behavior for the recorded values and stage. It does not
cover renderer execution, asset importers, nonuniform-scale decomposition,
shear policy, time-sampled op interpolation, or half precision.
