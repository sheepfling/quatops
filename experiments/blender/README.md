# Blender capture projects

Blender capture programs live in versioned directories and emit selected native
quaternion-converter witnesses to a temporary file. Validate them and write a
review copy with provenance using
[`scripts/retain_engine_witnesses.py`](../../scripts/retain_engine_witnesses.py).

- [Blender 5.1.2](5.1.2/README.md): minimal quaternion conversion capture.

These scripts are auxiliary evidence; they do not add a Blender dependency to
QuatOps or run inside package import.
