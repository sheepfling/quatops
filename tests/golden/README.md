# Native engine fixtures

Engine runtime output is kept under `tests/golden/<engine>/<version>/` so
captures from different engine releases can coexist. The canonical filename is
`native_rotation.json`; it is generated by the corresponding project under
`experiments/` and is not an output from QuatOps or SciPy.

Current engine/version captures are Unreal 5.7.4, Unity 6000.5.2f1, Godot
4.7-stable and 4.8-dev1, and Blender 5.1.2. Keep each future build in a new
versioned sibling directory.

The Python test suites consume these frozen captures after the engine process
has exited. They separately compare results with QuatOps representations and
SciPy's matrix/rotation formulas.

External math-library and transport fixtures use their own versioned trees:

```text
tests/golden/oracles/<library>/<version>/
tests/golden/transports/<format>/<spec-version>/<loader>/<version>/
```
